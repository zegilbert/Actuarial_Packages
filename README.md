# Actuarial_Packages
This is my R final project I did in "MIS 4470 - Practical Computing Data Analytics". It explores two R packages called "lifecontingencies" and "ChainLadder" and demonstrates the transformations to infer information regarding mortality rates, company reserves, and solve financial mathematics problems. If you're interested, feel free to download the project and try using R studio to figure out the SOA questions that I have within the "Materials_Questions" folder!
