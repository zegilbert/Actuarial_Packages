# Actuarial_Packages
This is my R final project I did in "MIS 4470 - Practical Computing Data Analytics". I explore two R packages called "lifecontingencies" and "ChainLadder" where I transform data to infer information such as mortality rates and company reserves. Financial mathematics problems from the Society of Actuaries (SOA) are considered as well. If you're interested, feel free to download the project and try using R studio to figure out the SOA questions that I have within the "Materials_Questions" folder!
